# campus-life-super-app
Created as an assignment for my Web Development class. It is an app that has different features intended to improve life on my college's campus. These features include a map, a forecast page, and a quote generator, for inspiration.
My original plan was to utilize web scraping, but that turned out to be too difficult with my current knowledge and skills, so I used APIs provided by zenquotes.io and weatherAPI.com, as well as bootstrap, and basic HTML, CSS, and Javascript.
To set up and deploy, simply clone the repo, and run on a local server, no extra steps necessary.
There are currently no plans for future additions.
